# .github

Organization-wide **community health files** and the **public profile README** for
NextProject13.

The files here act as **defaults** for every repository in the org that does not define
its own:

| File | Purpose |
| --- | --- |
| `profile/README.md` | Rendered on the public org profile page |
| `SECURITY.md` | Default security / vulnerability-reporting policy |
| `CONTRIBUTING.md` | Default contribution guidelines |
| `CODE_OF_CONDUCT.md` | Default code of conduct |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull-request template |
| `.github/ISSUE_TEMPLATE/` | Default issue templates |

A repository that ships its own copy of any of these overrides the org default.

> Member-only internal docs (branching, ports, deployment) live in the private
> [`.github-private`](https://github.com/project-aemr-13/.github-private) repo.
