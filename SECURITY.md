# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any NextProject13 project, please report it
**privately**.

- **Email:** [tech@project13.ro](mailto:tech@project13.ro)
- Do **not** open a public issue, pull request, or discussion for security reports.

Please include, where possible:

- A description of the vulnerability and its impact
- Steps to reproduce (a proof of concept helps)
- The affected repository / service and the version or commit

We aim to acknowledge reports within **3 business days** and will keep you informed as we
investigate and remediate. Please give us a reasonable window to address the issue before
any public disclosure.
